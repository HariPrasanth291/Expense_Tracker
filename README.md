Expense Tracker 💰

A responsive Expense Tracker web application that helps users manage their income and expenses, monitor their balance, and visualize spending habits through charts.

🚀 Features

* Add, edit, and delete income and expense transactions.

* View total income, total expenses, balance, and saving rate.

* Visualize income and expenses using charts.

* Analyze expenses by category using a doughnut chart.

* Search and filter transactions.

* Filter transactions by date and time period.

* Export transaction data to CSV.

* Save transaction data using browser local storage.

* Responsive design for desktop and mobile devices.

💻 How to Run the Project

Download or clone this repository.

Open the project folder in Visual Studio Code.

Open index.html in your browser.

Alternatively, install the Live Server extension in VS Code, right-click index.html, and select Open with Live Server.

💾 Data Storage

The application stores transaction data in the browser's local storage. Data remains available in the same browser unless the local storage is cleared or the browser data is removed.
